Keep the library in sync

Recommended

With this on, CineSnip checks your libraries for changes and keeps the quote-search cache current on its own: new titles get their subtitles extracted automatically, and titles removed from Plex have their cache entries cleared out (behind a two-layer safety check, so a Plex outage or a dead drive is never mistaken for real removal). It's also what lets /snip search reach titles it hasn't indexed yet, instead of only the ones already cached.

Search itself is already proven fine at real scale — on the reference install's index (~10.7k titles, ~7.5M subtitle entries), a full-library search measures 0.04–4s, with the slow end only hit by queries whose words are individually too common for the index to narrow much. So this isn't a search-performance trade-off. The one reason to leave it off is the initial extraction cost for a very large, not-yet-cached library — the first backfill has real CPU work to do. You can change this later from Settings.
